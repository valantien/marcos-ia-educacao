# Glossário

Os termos que aparecem no site, em linguagem simples. A lista cresce: qualquer termo que um professor do GT não entender vira verbete.

## Sobre os documentos

**Marco regulatório.** Qualquer documento oficial que orienta ou regula um tema: lei, decreto, resolução, parecer, guia, referencial.

**Ficha.** O arquivo que descreve um documento do acervo: o que o texto oficial diz, o que significa na prática e de onde vem.

**Esfera.** De onde vem o documento: internacional (organismos como UNESCO e OCDE), federal, estadual ou municipal.

**Natureza: vinculante, orientador, não vigente.** *Vinculante* é obrigatório para quem a norma alcança. *Orientador* é recomendação: mostra o caminho, mas não obriga. *Não vigente* ainda não vale, como um projeto de lei em tramitação.

**Lei, decreto, resolução, parecer.** A *lei* é aprovada pelo Poder Legislativo. O *decreto* é editado pelo chefe do Executivo para regulamentar ou organizar. A *resolução* é uma norma de um órgão, como o Conselho Nacional de Educação. O *parecer* é a análise de um conselho sobre um tema; no CNE, ele passa a valer depois de homologado.

**Homologação.** A aprovação de um parecer do CNE pelo ministro da Educação. Só depois dela o parecer passa a valer.

**Soft law.** Recomendações de organismos internacionais (UNESCO, OCDE) que não obrigam, mas influenciam as políticas dos países.

**Documento correlato.** Documento que não trata de IA, mas é base para o uso de IA na escola, como a lei de proteção de dados (LGPD).

**Fonte oficial e fonte secundária.** *Oficial* é o próprio órgão: Diário Oficial, site do ministério, UNESDOC. *Secundária* é quem fala sobre o documento: notícia, blog, escritório de advocacia. O acervo prefere sempre a oficial.

**Selo de verificação.** Mostra em que fase está cada ficha: *Rascunho* (ninguém conferiu ainda), *Parcial* (conferência incompleta), *Conferido* (dois curadores conferiram na fonte oficial) e *Em revisão* (o documento mudou e a ficha voltou para conferência). Antes de citar, prefira as fichas Conferido.

**Letramento em IA.** Entender o que é a IA, como funciona, quais são seus limites e riscos, para usá-la com critério.

## Sobre o projeto e a tecnologia

**Curadoria.** Escolher, ler, resumir e conferir cada documento. É o trabalho dos professores do GT.

**Protocolo de Curadoria.** As regras aprovadas pelo GT que dizem o que entra no acervo e como cada ficha é conferida. Quem decide é o protocolo, e na dúvida o GT decide por consenso.

**Base de conhecimento.** Um conjunto organizado de informações confiáveis que uma pessoa ou uma IA consulta antes de responder. Exemplo: em vez de perguntar ao ChatGPT "o que a lei diz?", você entrega a ele as fichas do acervo.

**Assistente de IA (chatbot).** Programa que conversa por texto, como ChatGPT, Gemini ou Claude no navegador.

**Agente de IA.** Assistente que, além de conversar, executa tarefas: lê arquivos, navega em pastas, monta documentos. Exemplos: Claude Code, Codex, Google Antigravity.

**Prompt.** O pedido que você escreve para a IA.

**Alucinação.** Quando a IA inventa uma informação com cara de verdadeira, como uma lei que não existe. Uma base de conhecimento ajuda a evitar.

**Repositório e GitHub.** Um repositório é uma "pasta pública na internet" que guarda arquivos e registra cada mudança. O GitHub é o site que hospeda essas pastas.

**Maintainer.** Palavra inglesa para "mantenedor": quem cuida do repositório. Recebe as sugestões, aplica o Protocolo de Curadoria, faz a triagem e aceita as mudanças. É o termo usado no GitHub e em projetos abertos.

**Site estático e GitHub Pages.** Este site: páginas prontas, publicadas de graça a partir do repositório pelo GitHub Pages.

**Arquivo Markdown (`.md`).** Texto simples com marcações leves (títulos, listas), fácil de ler por pessoas e por IAs. Cada ficha do acervo é um arquivo Markdown.

**`llms.txt` e `AGENTS.md`.** "Bilhetes" deixados no site e no repositório para que as IAs saibam como usar o acervo.

**Vibe coding.** Criar sites e ferramentas conversando com uma IA, sem saber programar. Foi assim que este site foi construído.
