# Como contribuir

Não é preciso saber programar para ajudar. Há três formas de participar:

- **Sugerir um documento** oficial sobre IA na educação que ainda não está no acervo.
- **Conferir uma ficha**, comparando-a com o documento oficial.
- **Fichar um documento**, para quem edita o repositório.

O passo a passo de cada uma está em [`site/pages/como-contribuir.md`](site/pages/como-contribuir.md). Antes de começar, leia as [regras de curadoria](site/pages/curadoria.md).

Sugestões e correções podem ser enviadas abrindo uma *issue* neste repositório. Mudanças grandes entram por *pull request*, para revisão do maintainer.

Ao contribuir, você concorda que o seu texto fica sob a mesma licença do acervo (ver [`LICENSE.md`](LICENSE.md)).
